# Сервис недельного расписания

## Точка входа в админке

| Параметр | Значение |
|----------|----------|
| Пункт меню | Сервис расписаний (`scheduleService`) |
| URL | `/schedule-service` |
| Имя маршрута | `weekly-schedule.index` |
| Редиректы | `/schedules`, `/weekly-schedule` → `/schedule-service` |
| Страница | `resources/js/Pages/WeeklySchedule/Index.jsx` |

## Назначение

Создание и управление недельным расписанием академии:

- одно расписание на календарную неделю (начало — понедельник);
- виды: **Общее** (день × здание × зал) и **Группа** (неделя одной группы);
- визуальная ось времени с метками **30 минут**;
- ИИ + детерминированный планировщик ставят занятия на сетке планирования **5 минут**;
- блоки занятий с группой, предметом, преподавателем и временем;
- проверка конфликтов; черновик / публикация; копирование прошлой недели; очистка таймлайна;
- рабочие часы недели; учебное окно курса (смена).

## Модель данных

### `academy_buildings` / `academy_rooms`

Локации и залы (seed). Управление: Настройки → Академия.

### `schedule_weeks`

| Поле | Описание |
|------|----------|
| `week_start_date` | Уникально, понедельник |
| `week_end_date` | Пятница той же недели (доска пн–пт) |
| `work_starts_at`, `work_ends_at` | Рабочие часы недели (в настройках UI — шаг 30 мин) |
| `status` | `draft`, `published`, `locked` |
| `published_at`, `published_by` | При публикации |

### `scheduled_lessons`

Связь недели, здания, зала, `academy_class_id`, `teacher_id`, `lesson_id`, дата, начало/конец, заметки, цвет, статус.

### `schedule_ai_runs`

Журнал ИИ-прогонов: промпт, снимок preferences, метрики, отчёт, предупреждения, статус.

### `courses.study_starts_at` / `courses.study_ends_at`

**Учебное окно** (смена) на весь курс. Все группы курса ставятся только внутри этого окна. Редактирование: Курсы и группы → настройки курса.

Типичные смены после миграции:

- первая смена: `08:00`–`13:00`
- вторая смена: `13:00`–`18:00`

Курсы распределяются по сменам с балансировкой по недельной нагрузке часов.

### Связанные сущности

- классы: `academy_classes` (опционально `color`; PHP `AcademyClass`)
- предметы: `lessons` (опционально `duration_minutes`)
- преподаватели: `teachers`
- назначения: `class_lessons` + `class_lesson_teacher` — **несколько преподавателей** на ClassLesson (`hours` на преподавателя); допуск через `lesson_teacher`

## Сетка: визуал и планирование

| Слой | Шаг | Назначение |
|------|-----|------------|
| Визуальный таймлайн | `VISUAL_STEP_MINUTES = 30` | Метки строк / плотность доски (вид не меняется) |
| Планирование / ИИ | `GRID_STEP_MINUTES = 5` | Snap размещения, перерывы (напр. 10 мин), упаковка |

Константы: `App\Services\WeeklySchedule\ScheduleConflictService`.

Блоки позиционируются по точным минутам начала/конца, поэтому смещения на 5 минут корректно отображаются на 30-минутных рядах.

## ИИ-распределение (гибрид)

Процесс:

1. Промпт в модалке ИИ-помощника (режимы: **Правка** / **Создать новое**).
2. В режиме создания таймлайн сначала очищается, затем идёт распределение.
3. LLM переводит промпт в компактный JSON **preferences** (не в расстановку слотов).
4. `DeterministicSchedulePlanner` ставит сессии по жёстким ограничениям.
5. Отчёт + рекомендации; preferences сохраняются в `schedule_ai_runs` (блок «интерпретация» пользователю не показывается).
6. В модалке кнопка **Инструкция** — список поддерживаемых рычагов.

### Основные рычаги планировщика (примеры)

| Рычаг | Типичная preference |
|-------|---------------------|
| Длительность урока | `default_session_minutes` (напр. 120); жёстко: два одинаковых 1ч подряд → один блок 2ч |
| Перерыв между уроками | `min_break_minutes` (напр. 10) — на сетке 5 мин соблюдается |
| Макс. часов/день на группу | `max_group_daily_minutes` |
| Макс. часов/день на преподавателя | по умолчанию **480** (8 ч) |
| Одно здание в день | `same_building_per_day` |
| Компактный день / макс. окно | `group_rules[].max_internal_gap_minutes` |
| Смена курса | окно `study_*` курса (жёстко), без массового day-half из промпта на все группы |

Сервисы:

- `App\Services\WeeklySchedule\WeeklyScheduleAiService`
- `App\Services\WeeklySchedule\DeterministicSchedulePlanner`
- `App\Services\WeeklySchedule\ScheduleConflictService`

Для AI-запроса в контроллере поднят лимит времени (`set_time_limit(300)`): полный прогон часто превышает default 30 с PHP-FPM.

### Кнопка «Учесть рекомендации»

**Учесть рекомендации и распределить снова** **не меняет** назначения преподавателей в БД. Она дописывает текст рекомендаций к промпту и снова запускает **Создать новое**. Добавление/деление часов преподавателей — в Курсах и группах (или скриптами).

Предупреждения о неразмещённых часах чаще означают **нет свободного слота** (окно курса, залы, конфликты), а не обязательно нехватку преподавателя.

## Интерфейс

1. **Шапка** — неделя, prev/next, статус, настройки, копирование, очистка, ИИ, публикация.
2. **Вкладки вида** — Общее / Группа (выбор группы в тулбаре).
3. **Палитра уроков** — остаток недельных часов по группа+урок+преподаватель; drag на доску.
4. **Таймлайн** — пн–пт; липкая колонка времени; блоки (drag/resize с UI-snap 30 мин при ручном редактировании).
5. **Модалка ИИ** — статус подключения, промпт, история, инструкция, подтверждение / частичное / отчёт.

## Проверка конфликтов

Пересечение интервалов `[starts_at, ends_at)` для одного зала, преподавателя или группы; плюс неверный зал/здание и диапазон времени.

Публикация блокируется при конфликтах.

## Видимость в mobile API

Мобильное приложение не видит черновики администрации.

| `status` недели | Mobile |
|-----------------|--------|
| `draft` | Скрыта |
| `published` | Официальное расписание |
| `locked` | Как официальная (зафиксированная; UI пока не выставляет) |

На официальной неделе отдаются уроки со статусами `published`, `cancelled`, `moved`. `draft` и `scheduled` скрыты (`scheduled` — статус размещения по умолчанию, в том числе для уроков, добавленных после Publish без повторной публикации).

Текущая неделя (без `?week=`) считается в `config('app.timezone')` = `Europe/Rome` (`APP_TIMEZONE`). Date-only поля `week_start_date` / `lesson_date` массово не конвертируются.

Эндпоинты: `GET /api/v1/schedule` (student, свой класс), `GET /api/v1/children/{student}/schedule` (parent, только `student_parent`) и `GET /api/v1/teacher/schedule` (teacher, свои `ScheduledLesson.teacher_id` по всем классам; есть `academy_class`, roster учеников нет). См. [API.md](API.md).

## Ограничения

- Доска только пн–пт (суббота/воскресенье не показываются).
- Ручной drag/resize в UI по-прежнему с шагом 30 мин; ИИ использует 5 мин.
- Кнопка PDF — заглушка.
- Учебные окна курсов узкие (≈5 ч); крупные курсы могут упираться в вместимость залов даже при достатке преподавателей.
- Статус `locked` в схеме есть, в UI пока не выставляется.
