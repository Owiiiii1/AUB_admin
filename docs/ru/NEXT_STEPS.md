## Текущий технический приоритет: API Foundation

Разработку Flutter **можно вести параллельно** с web/backend. Мобильные **функции** требуют стабильного API-контракта.

Старое правило «не начинать mobile до стабилизации web» **снято**.

### API Foundation (следующий крупный этап — не реализован)

- `routes/api.php` (или эквивалент) и версионирование API
- Token authentication — **Laravel Sanctum рекомендуется как кандидат**, не как утверждённое решение
- Flutter login, `/me`, безопасный logout / revoke токена
- Авторизация акторов student / parent / teacher / staff в API
- API Resources / DTO
- Формат ошибок
- Rate limiting
- Базовые integration tests
